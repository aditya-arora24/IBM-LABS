IBM Data Science Professional Certificate Labs & Projects

This repository contains my work, labs, assignments, notebooks, and projects completed as part of the IBM Data Science Professional Certificate offered through Coursera and IBM. The program covers the complete data science workflow, including Python programming, SQL, data analysis, data visualization, machine learning, generative AI, and an end-to-end capstone project.

About My Journey

I completed this professional certificate over a period of approximately 4–5 months while simultaneously pursuing my undergraduate studies at Plaksha University and the IIT Madras BS Degree in Data Science and Applications.

Managing these commitments required balancing coursework, assignments, exams, and independent learning while maintaining strong academic performance. One of the most rewarding aspects of this program was seeing significant overlap between the certificate content and my university curriculum. Topics such as SQL, Data Analysis, and Machine Learning reinforced concepts I was learning academically while providing additional hands-on industry-focused exposure.

Rather than focusing solely on theory, this program emphasized practical implementation through labs, projects, coding exercises, and real-world datasets. Every course contributed toward building a stronger understanding of how data scientists approach problems from data collection and cleaning all the way to model development and communication of insights.

Capstone Project

The highlight of the certificate was the Applied Data Science Capstone, where I applied the concepts learned throughout the program to a complete real-world project. This experience involved data collection, preprocessing, exploratory analysis, visualization, feature engineering, machine learning, and communicating results through a structured workflow. It was the closest representation of what a real data science project looks like from start to finish.

Beyond Technical Skills

One of the most underrated parts of this certificate was the career-focused content. The modules covering resumes, portfolios, networking, and interviews were just as valuable as many of the technical lessons. Technical knowledge is important, but learning how to present projects, communicate findings, and showcase skills effectively is equally essential for building a career in data science.
